# Support

## Public support

Use [GitHub Issues](https://github.com/edilec/svg-semantic-layout-auditor/issues)
for reproducible bugs, false positives, documentation gaps, and focused feature
requests.

Include:

- the package version or commit;
- the command and relevant options;
- a minimal synthetic SVG;
- the observed finding or output; and
- the expected behavior.

Public support is best-effort. The project does not include private SVG review,
accessibility certification, browser compatibility certification, or a service
level agreement.

## Private security reports

Use [SECURITY.md](./SECURITY.md), not a public issue, when the report may expose
a vulnerability.
